# Provenance

This directory was the standalone `aimpoint-validation-suite` companion repository, folded into
aimpoint on 2026-09-15 when that repository was retired. Only the files were carried over: the
original commit history was not recoverable at fold time, so this arrives as a single commit.

Contents: a biosecurity refusal and over-refusal pack, a biomedical capabilities catalog, and
three Harbor task adaptations (screening-tripwire-clustering, clinical-abstention-under-shift,
dual-use-target-triage). Author metadata in the task files is intentionally anonymized.
